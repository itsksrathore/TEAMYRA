# Changelog

All notable public releases of TEAMYRA are documented here.

## 1.0.0 — 2026-10-04

First stable public release.

### Highlights
- minimal Tasks + Agents desktop workflow
- Claude Code, Codex and Antigravity worker integration
- embedded normal ChatGPT web worker
- localhost HTTP and stdio MCP transports
- one-click MCP registration for supported local provider CLIs
- multi-account profile support where provider isolation is verified
- automatic worker routing, cooldown and failover
- detached/resumable jobs and task graphs
- isolated Git worktrees, review loops and conflict-resolution backend
- project memory, handoffs, recovery and observability
- workspace-scoped filesystem, terminal and Git tools
- idle sleep and wake-on-demand runtime
- self-contained Windows core and NSIS packaging
